# Supplementary Table S1. Analysis provenance for primary, descriptive, exploratory, and legacy results

Date prepared: 2026-06-15; updated for expanded HCP-YA evaluation and cohort accounting on 2026-07-03; updated for completed new-25 paired ablation on 2026-07-04; updated for paired simple baseline, seed pilot, and LOSO local pilots on 2026-07-06

Purpose: This table documents which analysis outputs are used in the current manuscript, which outputs are descriptive or exploratory, and which legacy or pilot outputs must not be reported as primary results. It is intended to prevent accidental mixing of pilot, legacy, and final reporting values.

Data source note: The fMRI inputs used by the current analyses should be described as processed HCP-derived regional time-series files with mixed provenance: public NPI repository resources released with Luo et al. and locally processed HCP-derived files retained in the current project. The project contains standardized `sub-*_bold_360.npy` model inputs for the 33-subject manuscript cohort, a 25-subject fixed-list traceable post-configuration HCP-YA evaluation, and a separate 20-subject legacy expanded robustness batch. These three project-level batches are non-overlapping, giving 78 provenance-documented HCP-derived subject-level inputs for project accounting only. Original HCP imaging directories were not fully retained after conversion for all earlier project inputs, so the reproducibility record is the combination of subject identifiers, processed 360-column arrays, processing/training scripts, quality-control summaries, and analysis provenance tables. For the new 25-subject fixed-list traceable HCP-YA evaluation, four HCP resting-state dense time-series files per subject were retained in `prespecified_hcp_minimal_dtseries/`, parcellated with Connectome Workbench and the HCP-MMP1 360-region dlabel, merged into 4800 x 360 arrays in `prespecified_hcp_360_inputs/`, and recorded in `prespecified_hcp_provenance/`. These data should not be described as wholly taken from the public NPI repository, nor as a complete raw-image reprocessing archive.

## S1C. Reporting rules used in the current manuscript

1. Values listed as primary may be used for main-text numerical claims.
2. Values listed as descriptive may be used only with non-inferential language.
3. Values listed as exploratory may be reported only as candidate workflow outputs and not as definitive validation.
4. Values listed as legacy, pilot, or non-primary must not be used as current manuscript results.
5. Any future manuscript revision that changes a numerical value should add the source file, analysis unit, sample count, and interpretation status to this table before submission.
