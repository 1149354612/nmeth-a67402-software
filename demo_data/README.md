# Simulated demo data

This folder contains a small simulated dataset that is used only to verify that
the code package executes.

Files:

- `demo_simulated_360_timeseries.npy`: a simulated `240 x 360` time-series
  array.
- `demo_region_centroids.csv`: simulated region-centroid coordinates for 360
  regions.
- `demo_manifest.json`: dataset metadata and provenance notes.

The demo data are not HCP or F-TRACT source data and are not used as scientific
evidence in the manuscript.
